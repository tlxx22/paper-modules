# 时空预测论文与模块调研

本项目面向交通流量预测、时空电力负荷预测及相关多变量时序任务，整理 2023—2026 年的代表性端到端框架，并评估本地论文和模块代码能否迁移到新的时空预测模型中。

当前仓库以**文献调研、代码审阅与模型方案设计**为主，尚未提供统一的数据处理、训练和评测入口。

## 研究重点

- 时间侧：TCN、Transformer、频域方法、S4/Mamba、ODE/CDE 与多尺度时间建模。
- 空间侧：GCN/GAT、扩散卷积、自适应图、动态图、超图及因果图结构学习。
- 时空融合：串行堆叠、并行双流、交叉注意力、动态门控与同步建模。
- 综合评价：模型轻量化、长短期预测能力，以及对动态时空异质性的处理能力。

## 当前核心结论

1. 本地资料对**时间建模和双分支融合**的帮助最大；近三年材料中几乎没有可直接替换道路图 GCN 的成熟动态图代码。
2. 时间侧优先考虑 AMD 的 MDM/AMS、SST 式“局部专家 + Mamba 全局专家 + 动态路由”、WTConv1D，以及修正后的 ATFNet 时频分支。
3. 空间侧更稳妥的方案是保留物理道路或电网图，再增加 Graph-Agent、稀疏动态图或自适应残差图支路。
4. 融合侧优先比较 Add/Concat、CMA 与 FCM；只有轻量门控不能满足需求时，再使用更重的交叉注意力。
5. 文件名中的“即插即用”不代表代码可直接使用。部分本地实现存在参数未初始化、固定二维形状、复数运算错误或论文—代码不一致等问题，接入前应参考正式论文和官方仓库重写、测试。

## 推荐模型路线

```text
输入 [B,T,N,F]
  → RevIN/标准化与时间、节点嵌入
  → MDM 多尺度时间分解
  → {WTConv1D/局部窗口专家，Mamba-2 全局专家}
  → 长短期动态路由
  → {物理图局部传播，Graph-Agent 全局动态关系}
  → FCM 节点—时刻级融合
  → 直接多步预测头
```

该路线围绕一个统一问题展开：根据不同运行状态、节点和预测跨度，动态选择长短期时间感受野以及局部物理依赖与远程数据驱动依赖。

## 使用本地材料时的约定

- 优先阅读编号 `.1` 的英文原文和 `.0` 的代码；`.2/.3` 多为翻译、转载或推广性解读。
- 纯图像模块中的 H×W 空间轴不能直接解释为道路节点轴 N；不得仅通过 reshape 将视觉模块包装成交通图模块。
- 时间插件建议统一为 `[B·N,T,C] → [B·N,T,C]`，完整预测头再输出 `[B,H,N,F_out]`。
- 任何空间替代模块都应明确节点关系的构造方式，并通过节点置换等变性测试。
- 实验除 MAE、RMSE、MAPE 外，还应报告参数量、实际延迟、吞吐、峰值显存，以及不同预测跨度和异常状态下的分组误差。

## 建议实施顺序

1. 建立 `TCN/GRU + 物理图 GCN + 直接多步头` 基线。
2. 单独替换 MDM 或 WTConv1D，验证时间模块的独立收益。
3. 加入局部专家、Mamba 全局专家及长短期路由。
4. 增加物理图与 Graph-Agent 双空间支路。
5. 比较 Add、CMA、FCM 等融合方式。
6. 最后再探索 Sonnet/MVCA、Graph-BRA、Graph-WPO 等高风险方向。
